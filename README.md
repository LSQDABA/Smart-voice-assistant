# 嘎嘎鸭智能助手：热点新闻选股智能体

基于 GEC6818 开发板与嵌入式 Linux 的中文智能语音助手课程设计。系统通过 LVGL 构建触摸屏界面，使用百度语音识别完成语音转文字，再调用扣子智能体进行热点新闻选股问答，最终将大模型回答显示在开发板屏幕上。

## 项目简介

本项目围绕“嵌入式大模型应用与开发”课程设计，实现一个可运行在 GEC6818 开发板上的中文智能语音助手。用户点击屏幕上的“语音输入”按钮后，系统调用录音工具采集语音，将音频转换为百度语音识别接口需要的 WAV 格式，并把识别文字显示到问题输入框。用户确认后点击“发送按钮”，程序将问题提交到扣子智能体服务，并将流式返回的回答解析后显示在界面回答区域。

## 功能特性

- 基于 LVGL 的 800×480 触摸屏图形界面
- 标题、问题输入框、回答显示区、语音输入按钮、发送按钮、状态提示
- 使用 `arecord` / ALSA 采集语音，兼容开发板 48kHz 双声道录音
- 将 48kHz 双声道音频转换为 16kHz 单声道 WAV
- 调用百度语音识别接口，实现语音转文字
- 调用扣子 `v3/chat` 接口，接入热点新闻选股智能体
- 解析 SSE 流式返回，仅提取 `answer` 类型内容
- 使用后台线程处理录音和网络请求，避免阻塞 LVGL 界面
- 通过互斥锁、共享缓冲区和 dirty 标志安全刷新 UI
- 录音、网络、令牌或接口异常时，屏幕显示可读提示并保存日志
